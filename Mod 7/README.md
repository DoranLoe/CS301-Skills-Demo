## Three examples of NP
Issue: there are no problems GUARANTEED to be NP in a way that makes them not P.</br> 
P vs NP is still an unsolved problem. There are no problems that are for certain not P. Just very very likely not P.
### All P problems
By definition, P is a subset of NP therefore all P questions are NP.  
### All problems that are NP-complete
A problem is NP complete if it can "reduce" or be simplified/mapped onto, an NP problem. Since this type of complexity is transitive, If you can reduce a problem to a P problem, then it is a P problem. If you can reduce it down to an NP problem, then it is also an NP problem. If you can reduce it to a hypothetical NP problem that is proven non-P, then the problem is non-P, but no problem has been proven to be that way.
### NP-Itermediate problems
If we assume that P =/= NP, then by Ladner's Theorem made in 1975, there exists problems in NP that are neither P nor NP. [I had to look this one up](https://en.wikipedia.org/wiki/NP-intermediate)
