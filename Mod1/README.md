# CS301-skills-demo/Mod1
Repository for the module 1 assignments

# Contents
DistanceSquared.java, program that takes two integer commandline arguments: x and y, and prints the distance the origin squared. <br>
TwentyFivePerLine.java, program that prints 1000 to 2000 with 25 integers per line, uses only one for loop and one if statement.<br>
Ordered.java, program that takes three integer commandline arguments: x, y, and z, and prints true if they are in ascending or descending order.
